## Context

上一轮把工作台改成纸面布局时，留下两个布局问题：

**滚动归属错了。** 外层 `.layout` 是 `height: 100%` 的列向 flex 容器，里面的内容区是它的 flex 子项。**flex 子项的 `min-height` 默认是 `auto`**，意思是"不低于内容高度"。于是内容一高，子项就把父容器撑破，`height: 100%` 形同虚设，溢出跑到 body 上：

```
内层容器高: 1409   ← 应该是 900 − 顶栏 56 − 细线 2 = 842
内层最小高: "auto"
main高: 1409 = 内容高  ← main 长得和内容一样高，反而滚不动
滚动后 window.scrollY = 569   ← 滚的是整个页面
```

**页头没有和纸对齐。** 纸面两页承载一张 794px 的纸，纸是居中的，页头却左对齐在内容区边缘，两者左边缘差 47px。

## Goals / Non-Goals

**Goals:**

- 工作台的滚动只发生在内容区，页面本身不滚
- 侧栏能独立滚动，不连带内容区
- 每一页的页头与它下方的内容共用同一个横向框架
- 纸面页的页头与纸同宽、同位

**Non-Goals:**

- 不改任何业务逻辑、引擎、领域模型与存储结构
- 不做暗色模式、响应式重排等其它视觉工作
- 不新增依赖

## Decisions

### D1 用 `min-height: 0` 解除 flex 子项的隐式下限

这是 flexbox 里的经典陷阱：子项要能在父容器里收缩，必须显式把 `min-height` 从 `auto` 改成 `0`，否则内容高度成了不可突破的下限。

```
.layout-body  { flex: 1; min-height: 0; }        ← 内容区所在的列向容器
.layout-aside { min-height: 0; overflow-y: auto; }
.layout-main  { min-height: 0; overflow-y: auto; }
```

三处都要加：`layout-body` 是外层 flex 容器的子项（不收缩就撑破外层），`layout-main` 与 `layout-aside` 是 `layout-body` 的子项（不收缩就各自撑破）。

### D2 落地页不参与这套约束

落地页（`/`）是公开路由，渲染在 `DefaultLayout` 之外，走正常文档流，页面本身滚动是对的。所以不能给 `body` 加 `overflow: hidden`——那会把落地页也锁死。方案是让工作台自己把高度管好（`height: 100%` + `min-height: 0`），body 在工作台里就没有可滚的内容。

### D3 页头与内容共用一个框架，而不是各自居中

问题不是"页头没居中"，是**页头和它下面的内容没对齐**。修法有两条路：

```
路 A：让页头跟随内容      两者左边缘对齐，但页头是满宽的，纸仍居中 → 右侧仍然错位
路 B：让内容跟随页头      纸左对齐到页头边缘 → 纸不再居中，且右侧留白变大
路 C：让两者共用纸的宽度   页头与纸同宽、都居中 → 左右都齐
```

取路 C，因为纸面页的"内容"就是那张纸——页头与纸同框，是最直白的对应关系。

具体做法：把纸的宽度提成变量 `--paper-width`，纸面页的页头加 `.page-header--paper`（`max-width: var(--paper-width)` + 左右 auto 外边距）。

其它页面（导入 / JD / 版本列表 / 版本详情）本来就用 `.page`（max-width 1120px 居中），页头与内容在同一个容器里，天然对齐，不动。

### D4 顺手去掉重复内边距

`layout-main` 有 `padding: 20px 16px 48px`，而用 `.page` 的页面自己又加了一层 `padding`——顶部实际 40px、左右 32px。因为每个页面都自带内边距（`.page` / `.draft-main` / `.diagnosis-main`），去掉 `layout-main` 的那一层即可统一。

## Risks / Trade-offs

**[纸面页的副标题换行变多]** → 页头被约束到 794px，标题块分到的宽度变窄，副标题会多折一行。取舍是"标题与纸的左边缘严格对齐"，这比副标题少一行更重要；若嫌挤可以缩短副标题文案。

**[侧栏加了独立滚动后，底部说明在内容多时不再固定可见]** → 侧栏内容（导航 + 分区目录 + 底部说明）超过视口高度时整体滚动。这比"底部说明被挤出视口"更合理。

**[打印页不受影响]** → `/versions/:id/print` 是顶层路由，在工作台布局之外，纸张占满页面，滚动走正常文档流 ✓

## Migration Plan

1. `layout-body` / `layout-aside` / `layout-main` 补 `min-height: 0` 与各自的滚动
2. 去掉 `layout-main` 的重复内边距
3. `tokens.css` 引入 `--paper-width`，`ResumePreview` 改用变量
4. `main.css` 新增 `.page-header--paper`
5. 两个纸面页的页头用上该修饰类
6. 验证：逐页测量「页头左边缘 vs 内容左边缘」的差值；滚动后确认 `window.scrollY` 保持 0

**回滚**：纯 CSS 改动，无数据迁移。

## Open Questions

本设计无遗留开放问题。以下两项已定案：

| 问题 | 结论 | 落在 |
|---|---|---|
| 滚动归属 | 只滚内容区，侧栏独立滚 | D1 |
| 页头对齐方式 | 与纸同宽同位（路 C） | D3 |
