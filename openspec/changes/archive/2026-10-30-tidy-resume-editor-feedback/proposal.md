## Why

复查简历编辑页时发现三个问题，它们互相叠加，把"改简历"这件事弄得比实际更难。

**一、顶部那块结构问题横幅一直占着位置。** 「这份简历还有结构问题」是一个关不掉的整块提示，挂在纸的上方，无论预览还是编辑都在。它列的问题还不全——引擎查得出"结束时间早于开始时间""同一分区没按时间倒序""两段经历时间重叠"，横幅只查"缺公司名、缺职位、缺开始时间、分区是空的"。用户改完一个字段，横幅不消失，只是清单变短，于是这块长期占着纸面上方最好的那块地方。

**二、完整批注卡插在简历正文里。** 诊断意见是以整张卡片的形式塞在分区标题旁、条目头旁、要点下方，与右侧批注栏里的内容一模一样。同一件事在纸上出现一次、在右栏又出现一次，纸面被卡片切成一段一段，读起来不再是简历。

**三、同一批问题被说了三遍。** 结构问题在横幅里说一遍、在纸内批注里说一遍、在右侧批注栏里再说一遍。三处的措辞还不一样：横幅说"「美团」缺少公司名称"，诊断意见说"这段经历没有公司名称。"

这些不是个人偏好，是实现跑在了规范前面：规范写着「批注 SHALL 展示在纸右侧的批注栏中，而不是插在内容之间」，而纸内插槽正是这么插的。

## What Changes

**结构问题就地标注，不再有顶部横幅**

```
现在：                              改后：
┌ 我的简历 ──────────────┐        ┌ 我的简历 ──────────────┐
│ 我的简历是你唯一的事实来源…│        │ 简历以这一份为准…      │
│ ┌──────────────────────┐│        │ ┌──────────────────────┐│
│ │ ⚠ 这份简历还有结构问题 ││        │ │ 经历                 ││
│ │ · 「美团」缺少开始时间  ││        │ │ 2023-03 – 至今 后端   ││
│ │ · 「阿里」缺少开始时间  ││        │ │ ⚠ 缺少开始时间        ││
│ └──────────────────────┘│        │ │ · 负责接口开发        ││
│ ┌──────────────────────┐│        │ └──────────────────────┘│
```

结构问题由一套共用的检查得出，标注贴在出问题的那个条目或分区旁边，一眼能对上位置；页面顶部不再有集中的结构问题提示。

**纸面批注改成轻量摘要**

```
现在：要点下方插入整张批注卡         改后：要点下方一行摘要
· 负责服务端接口开发                  · 负责服务端接口开发
┌────────────────────────┐             ⚑ 2 条批注 · 只写了承担什么，没有结果
│ 高 责任无结果            │             ▾ 高 责任无结果 — 补上一个可衡量的结果
│ 建议怎么改：…            │             ▾ 中 表述笼统 — 换成具体的技术名词
│ [去修改][标记已处理][忽略] │           （完整批注卡留在右侧批注栏）
└────────────────────────┘
```

**批注顺序统一按简历位置**：现在编辑页按严重度排、诊断页按简历位置排，同一份简历在两个页面顺序不一样。

**窄屏折叠的批注栏看得见里面有什么**：折叠成 56px 时除了总数，还给出高/中/低三档的分布，点某一档直接按该严重度筛选。

**页头收紧**：标题、未保存标记、诊断计数、预览/编辑切换、保存、放弃修改、重新导入重新分层，副标题压成一行短句。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `resume-comment-anchoring`: 「编辑时批注与句子同屏」改为纸面只保留轻量行内批注、完整批注留在右侧批注栏；新增「结构问题就地标注」；「批注栏可折叠」补上折叠时的严重度分布；「从批注跳到编辑页时展开对应批注」改为定位 + 纸面标出 + 批注栏选中
- `resume-draft`: 「底稿以结构化内容保存并可直接编辑」的遗留问题提示改为就地标注，不做集中横幅；「分区字段的措辞跟随分区」补上结构标注用同一套说法
- `draft-diagnosis`: 「诊断覆盖三类焦点问题」区分严重程度的场景，说明引擎内部按严重度排序、界面一律按简历位置排列

## Impact

**代码**

- `frontend/src/engines/structure.ts`：新增。结构检查的唯一出处，诊断与纸面标注共用
- `frontend/src/engines/diagnose.ts`：结构类规则改为调用上面的模块，规则、严重度与文案不变
- `frontend/src/views/DraftView.vue`：删顶部横幅与视图内重写的结构检查；纸面结构标注；行内批注改轻量；页头重排
- `frontend/src/components/CommentSidebar.vue`：折叠态显示严重度分布
- `frontend/src/stores/draft.ts`：新增按简历位置排序的批注列表
- `frontend/src/stores/ui.ts`：删除无人使用的状态与方法
- `frontend/src/views/DiagnosisView.vue`：改用统一的批注顺序
- `frontend/src/components/ResumePreview.vue`：打印时隐藏纸面标注与行内批注

**不受影响**

- 不改诊断规则本身：规则、严重度、判断口径一律不变，只是结构类规则换了出处
- 不改预览模式的版式与导出
- 不改领域模型与存储结构
- 不新增依赖
