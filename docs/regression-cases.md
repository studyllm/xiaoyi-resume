# 回归用例库

人工验收的清单。自动化用例盯结构、字段、状态流转与不变量；**这份清单盯它们盯不到的东西**——颜色、悬停反馈、版式、分页、打印稿、键盘流、各档屏幕宽度。

- **什么时候用**：每次改动要发布之前；P5 的发布检查单（`docs/release-checklist.md`）以这份为底稿。
- **怎么用**：从上往下逐条走。**每条都写清了「做什么」和「看到什么算通过」**，不用自己想该看什么。发现不对就地记下来，别记在心里。
- **不在这儿**：结构、字段、状态流转、不变量那些由 500 多个自动化用例盯着，不重复。

> **最后复核**：2026-11-04 · 对应能力域版本见每条后面的标注

## 1. 黄金路径

一次完整投递：落地 → 导入 → 保存 → 诊断 → 生成 → 导出 → 复制。

### 1.1 落地页

- [ ] **打开落地页**：标题、副标题、主次两个 CTA 都在首屏；主 CTA 是实心主色，次 CTA 带边框 —— 通过：首屏能同时看到「导入我的简历」与「用示例简历试一遍」
- [ ] **两个 CTA 都能点**：主 CTA 跳到导入页，次 CTA 载入演示数据并进入工作台 —— 通过：两个都能走到工作台
- [ ] **落地页能整页滚动**，不被工作台布局框住 —— 通过：滚到底能看到页脚
- [ ] **顶栏与主内容同宽** —— 通过：顶栏左右边缘与首屏容器对齐

### 1.2 导入

- [ ] **粘贴文本后能解析出结构**：纸面出现四个分区（教育背景 / 工作经历 / 项目经历 / 专业技能），条目头带公司、职位、起止日期 —— 通过：纸面从抬头到最后一个分区完整呈现
- [ ] **解析结果能在纸上直接改**：改公司名，要点输入框即改，纸面下方不出现新的结构问题标记 —— 通过：改动留在纸面上，没有额外插入的行
- [ ] **保存前有身份询问**：未登录时保存会先问名字，确认后这次保存继续 —— 通过：身份对话框在保存时出现
- [ ] **重复导入会二次确认**：已有简历时再导入，弹框说清「会覆盖当前简历，已经生成的版本不会跟着改变」 —— 通过：弹框出现，且文案说了两件事
- [ ] **保存后进到编辑页**，编辑页展示同一份内容 —— 通过：内容与导入页看到的一致

### 1.3 上传 PDF

- [ ] **带文字层的 PDF 能解析出分区**：上传后纸面出现分区与起止日期 —— 通过：与粘贴同一份内容的结果一致
- [ ] **条目头与它的日期还在同一行**：条目头右侧的日期没有被拆到下一行 —— 通过：日期与公司职位同行
- [ ] **没有文字层的 PDF 给出出路**：上传扫描件后，界面说明没有可读取的文字层，并引导改用「粘贴文本」，焦点自动交到粘贴框 —— 通过：页签自动切回粘贴，粘贴框有焦点环
- [ ] **非 PDF 文件被拒**：把 `.txt` 改名成 `.pdf` 上传，界面按文件自身判定并说明 —— 通过：提示说的是这份文件怎么了、用户下一步能做什么

### 1.4 编辑与保存

- [ ] **保存后修订号递增**，页头的「未保存」标记消失 —— 通过：修订号 +1
- [ ] **有未保存修改时离开页面会问**：三个选择都在——保存并离开 / 放弃修改并离开 / 留在本页 —— 通过：弹框出现且三个选项齐全
- [ ] **「留在本页」真的留在本页** —— 通过：页面没跳

### 1.5 诊断

- [ ] **进入诊断页不自动诊断**：纸面是干净的，没有意见标记 —— 通过：点「开始诊断」之前页面上没有批注
- [ ] **诊断后意见落在具体句子上**，纸面对应位置高亮 —— 通过：点意见，纸面滚到并高亮那一句
- [ ] **诊断意见能改成「已处理」**，处理后不计入未处理数 —— 通过：批注栏的未处理数减一
- [ ] **不输出总分** —— 通过：页面上没有任何分数

### 1.6 生成版本

- [ ] **粘贴 JD 后能提取到要求条目**，并显示每条的命中情况 —— 通过：表格里逐条列出 JD 原句与强/弱/未覆盖
- [ ] **生成版本后进到版本详情**，正文能读 —— 通过：版本详情显示完整正文
- [ ] **版本正文与底稿隔离**：改了底稿，旧版本的正文与改动对照都不变 —— 通过：回到旧版本，正文与之前一字不差
- [ ] **同一份 JD 再生成一次，得到另一份并存快照** —— 通过：版本列表里多出一份，两份互不影响
- [ ] **版本里没有底稿之外的事实**：公司、项目、数字都不新增 —— 通过：逐条对照底稿，没有新增

### 1.7 导出与投递

- [ ] **导出的 PDF 带文字层**：在阅读器里能选中并复制简历里的文字 —— 通过：选中一段能复制
- [ ] **打印稿没有底色、虚线、外圈标记**，也没有顶栏、侧栏、页码、页眉页脚 —— 通过：打印预览里只有简历内容
- [ ] **三种导出格式内容一致**：纯文本、Markdown、PDF 的分区、条目、要点与日期表示相同，日期统一写成 `2021-03` —— 通过：逐项对照
- [ ] **复制正文能用**：复制后粘到别处，格式与屏幕上的一致 —— 通过：粘贴出来仍按分区分段

## 3. 空态与错误态

逐条对应 `docs/error-taxonomy.md` 的状态表。**每一条都要点得到**，不是看文档。

### 3.1 空态的三层结构

- [ ] 每个空状态都有**标题**、**说明**、**主动作**三层 —— 通过：标题是一句短句，说明另起一句，动作是一个能点的按钮
- [ ] 标题与说明不是同一句话 —— 通过：两句话说的不是一件事
- [ ] 有主动作时，按钮点了真的能改变这件事 —— 通过：点了之后状态确实变了
- [ ] 没有主动作时，说明里讲清了为什么没有 —— 通过：例如「没有可对照的改动」说明的是两者一致，不是一个能点的按钮

### 3.2 三种「还没有」分得清

- [ ] 还没诊断过 —— 显示「还没有诊断结果」，带发起诊断的入口
- [ ] 诊断过但零意见 —— 显示「没有查出问题」，**不**说成「还没有诊断结果」
- [ ] 有意见但被筛掉了 —— 显示「当前条件下没有批注」，带清除筛选

### 3.3 每条失败都给了下一步

- [ ] 解析失败 —— 说清没成什么，并告诉用户换一种带分区标题的写法再试
- [ ] 保存失败 —— 说清没成什么，并告诉用户重新解析再保存
- [ ] 生成失败、复制失败、JD 解析失败、缺少简历 —— 每条都有下一步
- [ ] 没有一条失败提示停在「XX 失败」

### 3.4 正向的空结果不是故障

- [ ] 「没有可对照的改动」看起来是好结果，不是页面坏了
- [ ] 「要求都能找到对应事实」看起来是好结果

## 4. 键盘流

`AGENTS.md` §5.6 的六项。**全程不用鼠标。**

| # | 操作 | 看到什么算通过 |
| --- | --- | --- |
| 4.1 | 在要点输入框里按 `Enter` | 新增一条要点，焦点落在新要点上 |
| 4.2 | 在要点输入框里按 `Shift + Enter` | 在要点内换行，没有新增条目 |
| 4.3 | 在空的要点输入框里按 `Esc` | 这条空条目被取消 |
| 4.4 | 在**已有内容**的要点里按 `Esc` | 只退出输入，不删内容 |
| 4.5 | 按 `Cmd / Ctrl + Enter` | 保存并退出编辑模式；若保存后仍有结构问题则留在编辑模式 |
| 4.6 | 用 `Tab` 在纸面字段间移动 | 顺序合理（抬头 → 分区 → 条目头 → 要点）；**焦点环始终看得见** |

补充：

- [ ] 只用键盘走完一次「新增条目 → 填公司 → 填要点 → 保存」
- [ ] 焦点环在每一处都可见，且不被底色吃掉

## 7. 视觉语言抽查

对照 `AGENTS.md` §4。这部分靠眼睛，静态扫描测不到。

- [ ] 一个界面上至多一个实心主色
- [ ] 纸面版式是单栏经典形态：分区标题加粗带下划线、条目头两端对齐、要点悬挂缩进
- [ ] **没有**双栏、侧边色块、头像、图标
- [ ] 编辑态的标记**不改变版式**：不加行、不占版面
- [ ] 悬停反馈细到行：抬头有多行时，鼠标在哪一行只有那一行变色
- [ ] 预览模式与打印稿**没有任何**底色、虚线、外圈
- [ ] 文字按钮常态是主色，悬停加一层淡青底
- [ ] 链接（`el-link`）悬停出现下划线，按钮不出现
- [ ] 删除入口是垃圾桶图标，淡色常显、悬停转警示色
